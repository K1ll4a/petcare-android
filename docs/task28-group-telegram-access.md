# Задача #28: состав группы, Telegram, ссылка на задачу и кеш аккаунта

Ветка: `feature/group-telegram-access` (от `feature/android-ios`). Исполнитель: Mobile №2.
Весь код — в общем модуле `shared/src/commonMain`, поэтому поведение одинаковое на Android и iOS.
Платформенные части — только приём ссылки `petcare://` (AndroidManifest + MainActivity, Info.plist + SwiftUI).

## Что сделано

| Требование | Где | Статус |
|---|---|---|
| Список участников, роль у каждого | «Настройки» → «Участники» (`AccountRepository.getMembers`) | готово, учебный сервер; на настоящем — `GET /spaces/{id}/members` уже в контракте, ждёт серверного входа |
| Выход из пространства (FR-23) | «Выйти из пространства» у участника; владельцу — объяснение | готово в учебном сервере; **серверного метода нет** (Backend #26) |
| Удаление участника владельцем (FR-22) | «Удалить» у других участников, только у владельца | то же |
| Передача владения (FR-22, BR-08) | «Передать владение», только у владельца; в группе всегда один владелец | то же |
| Скрытие недоступных роли действий | участник не видит «Удалить», «Передать владение», «Приглашения» | готово |
| Незавершённые задачи ушедшего — владельцу, история не меняется | `reassignOpenTasks` в учебных задачах | готово в учебном сервере; на настоящем это делает сервер |
| Привязка Telegram (FR-16, AC-08) | «Настройки» → «Telegram-напоминания» | готово: `ApiTelegramRepository` по API.md 1.2 §7.1 и учебная версия |
| Ожидание подтверждения | после выдачи ссылки — «Не подтверждено», проверка каждые 3 с и кнопка «Проверить» | готово |
| Вкл/выкл напоминаний, отвязка (FR-18) | переключатель меняется только по ответу сервера; отвязка с подтверждением | готово |
| Состояние после перезапуска | загружается с сервера при каждом открытии; учебный сервер хранит привязку на устройстве | готово |
| Ссылка из Telegram на задачу | `petcare://tasks/{task_id}?occurrence_id={id}` → вход (если нужно) → проверка доступа → карточка задачи | готово |
| Чужой аккаунт / потерян доступ | «Задача из ссылки недоступна этому аккаунту…» — без названия и данных задачи | готово |
| Очистка при выходе и отзыве доступа (FR-19) | выход — весь защищённый раздел; отказ сервера 403 — только это пространство, другие остаются | готово |
| Обновление | при открытии экрана, при возврате на передний план (Android и iOS), кнопка «Обновить» | готово |

## Зависимости, которых пока нет

- **Серверный вход Mobile №1 (#22)** — без токена настоящий сервер отвечает 401 на все методы, включая Telegram.
  Серверная привязка подключается заменой в `AppContainer`: `telegramRepository = serverTelegramRepository(BASE_URL, tokens)`.
- **Серверное управление составом (Backend #26)** — в `API.md` 1.2 выход, удаление и передача владения перечислены
  в «Не входит в этот релиз». Пути на клиенте **не выдуманы**: методы есть в `AccountRepository`,
  серверная реализация добавляется вместе с серверным `AccountRepository`.
- **Мост Telegram → приложение** — сервер открывает `petcare://…` через `GET /telegram/task/{id}`; до выдачи токена бота
  (`@BotFather`) проверяется ручным открытием ссылки (ниже).

## Сценарии для QA (одинаково на Android и iOS)

Учебный режим, пароль `demo12345`. «Семья»: владелец Гриша, участник Аня. «Дача»: владелец Олег, участник Гриша.

**Владелец**
1. Гриша → «Семья» → «Настройки»: «Ваша роль: владелец», у Ани есть «Передать владение» и «Удалить», есть «Приглашения».
2. Нажать «Выйти из пространства» нельзя: вместо кнопки — «сначала передайте владение».
3. «Передать владение» Ане → подтвердить → «Ваша роль: участник», кнопок управления нет, появилась «Выйти из пространства».
4. «Выйти из пространства» → подтвердить → открылся список: «Семьи» нет, «Дача» осталась.

**Участник**
5. Аня → «Семья» → «Настройки»: нет «Удалить», «Передать владение», «Приглашения»; есть «Выйти из пространства».

**Бывший участник**
6. Олег → «Дача» → «Настройки» → «Удалить» Гришу. Выйти.
7. Гриша: в списке только «Семья». Если Гриша был в «Даче» в момент удаления (второе устройство) — после «Обновить»
   или возврата приложения на передний план экран «Дачи» закрывается с сообщением «Доступ к пространству «Дача» закрыт»,
   «Семья» доступна.
8. Задачи Гриши в «Даче», которые не были выполнены, теперь у Олега; выполненные остались с исполнителем «Гриша».

**Telegram**
9. «Настройки» → «Подключить Telegram» → «Не подтверждено», видны ссылка и срок; кнопка «Открыть в Telegram».
10. Учебный режим: «Демо: нажать Start в боте» → «Подключён», переключатель «Напоминания» включён.
11. Выключить переключатель → «Ждём ответ сервера…» → «Напоминания отключены». Перезапустить приложение, войти → состояние то же.
12. «Отвязать Telegram» → подтвердить → «Не подключён».
13. Через 10 минут после выдачи ссылки «Демо: нажать Start» → ошибка «Ссылка истекла», привязка не подтверждена.

**Вход по ссылке из Telegram**
14. Android: `adb shell am start -a android.intent.action.VIEW -d "petcare://tasks/21"`.
    iOS Simulator: `xcrun simctl openurl booted "petcare://tasks/21"`.
15. Не войдя: экран входа с «Войдите, чтобы открыть задачу из Telegram» → войти Гришей → открылась «Задача из Telegram»
    («привить от бешенства», «Дача», срок с поясом Asia/Yekaterinburg).
16. Выйти → открыть ту же ссылку → войти Аней → «Задача из ссылки недоступна этому аккаунту…», название задачи не показано.
17. Повторить шаг 14 с запущенным приложением — ссылка открывается без перезапуска.
