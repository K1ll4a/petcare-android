## Что проверить Mobile №2

1. Открыть **корень репозитория**, ветку `feature/shared-auth-spaces`; выполнить запуск по README.
2. Войти Гришей, открыть «Семью», профиль, форму задачи; перейти в «Дачу», убедиться, что питомцы другие.
3. Создать пространство и пройти сценарий кода приглашения через два аккаунта на одном устройстве.
4. Выйти, убедиться, что защищённый экран не возвращается, затем запустить тесты.
5. Продолжать работу в этом же репозитории, без копирования проектов/Gradle/`.git` из архивов.

Подтверждение после реальной проверки: имя разработчика, дата, commit SHA, устройство/API,
результат сборки и сценариев, ссылка на свою ветку. Сейчас подтверждения ещё нет.

## Граница подключения Backend

`AccountRepository` описывает операции входа, регистрации, выхода, списка/создания пространств,
присоединения, списка/создания/отзыва приглашений. Его серверная реализация должна появиться рядом
с `ApiPetCareRepository` и заменить `DemoAccountRepository` в `AppContainer`.

Для интеграции нужны фактические URL и тела запросов/ответов, формат токена и его истечения,
данные пользователя, роль отдельно для каждого пространства, часовой пояс, дата истечения и статус
приглашения, формат ошибок и ошибок полей. Для изменяющих запросов стоит согласовать повтор после
тайм-аута, чтобы потерянный ответ не создавал второе пространство/приглашение.

Сетевые запросы питомцев/задач Mobile №2 сохранены с её допущениями по путям задач (см. `TaskEndpoints`).
В текущей учебной сборке они не вызываются. Скрытый `DevLoginTransport` удалён: вход должен идти через
экран, а 401 завершать сессию вместо автоматического входа тестовым пользователем.

При выходе: отменить запросы, удалить токен, очистить аккаунтные состояния и защищённый ViewModelStore,
вернуть вход; не ждать успешного ответа logout. При переключении пространства сохраняется защита
поколением запроса из `HomeController`. Проверить 401 и 403 в обеих реализациях репозиториев.

Удаление участника, выход из самого пространства и передача владения оставлены за границами этих задач.
